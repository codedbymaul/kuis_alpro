# C++ Algorithm & Programming

Repository ini berisi kumpulan program C++ yang dibuat untuk latihan pemrograman. Program-program ini bertujuan untuk memahami dasar-dasar pemrograman, penggunaan algoritma, dan cara menyelesaikan masalah menggunakan bahasa C++.

## Projects

### 01 — Predikat Nilai
- File: predikat_nilai.cpp
- Materi: Percabangan (Conditional Statements)
- Deskripsi: Program untuk menentukan predikat nilai berdasarkan nilai yang dimasukkan.

### 04 — FizzBuzz
- File: fizzbuzz.cpp
- Materi: Perulangan dan Percabangan (Loops and Conditionals)
- Deskripsi: Program yang menggunakan perulangan dan percabangan untuk menampilkan output sesuai aturan FizzBuzz.

### 15 — Subbarisan Maksimum
- File: sub_maksimum.cpp
- Materi: Algoritma Kadane (Kadane's Algorithm)
- Deskripsi: Program untuk mencari jumlah maksimum dari suatu subbarisan dalam kumpulan bilangan.

### 20 — Kasir Diskon Bertingkat
- File: kasir_diskon.cpp
- Materi: Operasi Aritmetika dan Percabangan
- Deskripsi: Program kasir sederhana untuk menghitung total belanja setelah mendapatkan diskon sesuai ketentuan.

### 34 — Peringkat Nilai Akhir
- File: peringkat_nilai.cpp
- Materi: Array dan Pengurutan Data
- Deskripsi: Program untuk mengolah nilai akhir dan menentukan peringkat berdasarkan nilai yang diperoleh.

## Technologies

Teknologi dan aplikasi yang digunakan dalam pengerjaan program ini antara lain:

- C++ sebagai bahasa pemrograman.
- GCC / G++ untuk melakukan kompilasi program.
- Visual Studio Code sebagai editor kode.
- Sublime Text sebagai alternatif editor kode.
- Acode untuk menulis dan mengedit kode melalui perangkat Android.

## How to Run

Untuk menjalankan program C++, file perlu dikompilasi terlebih dahulu menggunakan compiler G++.

Contoh perintah untuk mengompilasi program:

g++ predikat_nilai.cpp -o program

Setelah proses kompilasi selesai, program dapat dijalankan menggunakan perintah:

./program

Nama file pada perintah kompilasi bisa diganti sesuai dengan program yang ingin dijalankan.
