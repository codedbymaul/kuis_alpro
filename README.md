Getting Started

Prerequisites

Install a C++ compiler, such as GCC, and make sure it is accessible from your terminal.

Clone the Repository

git clone <repository-url>
cd <repository-folder>

Compile and Run

Compile the desired source file:

g++ soal-01-predikat-nilai.cpp -o program

Run the compiled program:

./program

Replace the source filename with the program you want to execute.
