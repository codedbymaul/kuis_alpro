Getting Started

Prerequisites

Make sure a C++ compiler, such as GCC, is installed and available in your terminal.

Compile and Run

Clone the repository:

git clone <repository-url>
cd <repository-folder>

Compile a program:

g++ soal-01-predikat-nilai.cpp -o program

Run the executable:

./program

Replace the source filename with the program you want to execute.
